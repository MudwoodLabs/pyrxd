Check a HashMark

Someone gave you a transaction number. This page reads the record inside it and says, in plain words, what that record does and does not establish.

What a HashMark is

A short record published on the Radiant blockchain. It carries a fingerprint of a file — not the file itself — and, in most cases, a signature. Publishing it puts that fingerprint in a block, and the further down the chain that block ends up, the harder its place in the order is to change.

What checking one can establish

That the fingerprint existed no later than the block that carried it, so whoever published it knew the file by then. If the record is signed and the signature checks out, that the holder of a particular key made that statement.

What it cannot establish

Not who wrote the file. Not who owns it. Not that they were first to it. Not where anyone was. And nothing whatever about whether what the file says is true.

Nothing here is uploaded

The record is read from a public blockchain server. If you check a file against it, the file is hashed inside this browser and never leaves this machine.
